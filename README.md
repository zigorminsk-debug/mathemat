# Предел

Офлайн-учебник математического анализа и сопутствующих теорий для Android 7.0 и новее. В курсе 14 разделов и 42 содержательных урока: от логики и действительных чисел до многомерного анализа, меры Лебега, функционального анализа, дифференциальных уравнений и рядов Фурье. Каждый урок содержит теорию, примеры, доказательства и задачи с решениями.

Приложение работает без интернета и не запрашивает разрешение `INTERNET`. Доступны поиск по полному тексту, закладки, отметки об изучении и настройка размера текста. Прогресс и закладки хранятся на устройстве; при удалении приложения или очистке данных они могут исчезнуть.

## GitHub Actions и APK

При каждом push в ветку запускается [Android APK](../../actions/workflows/android.yml). После успешной сборки APK доступен в разделе **Artifacts** соответствующего запуска. `versionCode` равен номеру запуска workflow и увеличивается при новом запуске. Повторная попытка того же запуска (Re-run) сохраняет прежний номер; для новой версии отправьте новый commit в ветку.

- Если оба секрета подписи настроены, создаётся `predel-release-signed` с `app-release.apk`. Его сертификат проверяется по закреплённому отпечатку в `signing-cert.sha256`.
- Если оба секрета отсутствуют, собирается только **предварительный** `predel-preview-not-updatable-to-release`. Это debug APK с другим `applicationId` (`by.mathemat.predel.preview`) и временной debug-подписью. Он предназначен лишь для ознакомления, не является постоянным релизом и **не обновляется поверх release**. Если задан только один из двух секретов, сборка намеренно завершается ошибкой.

### Постоянный ключ подписи

Ключ создан отдельно от публичного репозитория. Он не должен попадать в Git, артефакты Actions или логи. В GitHub → **Settings → Secrets and variables → Actions → New repository secret** необходимо добавить:

1. `ANDROID_KEYSTORE_BASE64` — всё содержимое файла с Base64-представлением PKCS#12-хранилища.
2. `ANDROID_KEYSTORE_PASSWORD` — пароль хранилища и ключа.

Alias внутри хранилища: `mathemat`. Полученный закрытый архив с хранилищем и паролем нужно **сохранить в защищённом месте и не публиковать**. GitHub не позволяет прочитать значение секрета обратно: одних секретов недостаточно для надёжной резервной копии. При наличии `gh` с правом управления секретами можно использовать `scripts/upload-signing-secrets.sh` и каталог с файлами резервной копии — скрипт предварительно проверит отпечаток и соответствие Base64-файла хранилищу.

Обновление поверх предыдущего релиза возможно только при сохранении **того же закрытого ключа**, `applicationId` (`by.mathemat.predel`) и неуменьшающегося `versionCode`. APK, подписанный другим ключом, не сможет обновить установленное приложение; смена ключа без предусмотренной Android схемы ротации сломает совместимость. Отпечаток намеренно закреплён, чтобы случайно не выпустить несовместимую версию. Предварительную debug-версию при необходимости удалите отдельно.

Для восстановления сборки из резервной копии добавьте те же два секрета и запустите workflow повторно. Если нет кнопки ручного запуска для ветки, достаточно push в эту ветку: `workflow_dispatch` в GitHub может требовать присутствия workflow в ветке по умолчанию.

## Разработка

Нужны Node.js 22, Java 17 и Android SDK с платформой 35. Gradle Wrapper закреплён на версии 8.9 с проверкой SHA-256.

```sh
npm ci
npm run build:content  # после изменения content/
npm test
npm run preview        # локальный просмотр интерфейса на порту 4173
./gradlew :app:assembleDebug
```

Веб-ресурсы упаковываются в APK; Android `WebView` загружает их с локального защищённого origin, не открывая доступ к сети. Исходные уроки находятся в `content/lessons/*.md`, оглавление — в `content/book.json`. При сборке текста формулы предварительно преобразуются KaTeX; сгенерированный `app/src/main/assets/content.js` хранится в репозитории и проверяется тестом на воспроизводимость. Шрифты и KaTeX поставляются вместе с приложением, их лицензии находятся в `app/src/main/assets/vendor/licenses/`.

Для локального **release** задайте `MATHEMAT_KEYSTORE_PATH` (путь к тому же PKCS#12) и `MATHEMAT_KEYSTORE_PASSWORD`, затем выполните `./gradlew :app:assembleRelease -PappVersionCode=N`. Никогда не добавляйте ключи и пароли в Git.
