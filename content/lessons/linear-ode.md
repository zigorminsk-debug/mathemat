## Линейное уравнение первого порядка

Для непрерывных $p,q$ на интервале рассмотрим $y'+p(t)y=q(t)$. Интегрирующий множитель $\mu(t)=\exp(\int p(t)dt)$ удовлетворяет $\mu'=p\mu$. Поэтому

$$(\mu y)'=\mu q,\qquad y(t)=\mu(t)^{-1}\left(C+\int_{t_0}^{t}\mu(s)q(s)\,ds\right).$$

Начальное условие однозначно определяет $C$. Формула работает на любом интервале непрерывности коэффициентов; её вывод — правило производной произведения, а не формальный набор операций с дифференциалами.

**Пример.** Для $y'+y=1$, $y(0)=0$ берём $\mu=e^t$: $(e^ty)'=e^t$. Получаем $y=1-e^{-t}$.

## Второй порядок с постоянными коэффициентами

Для однородного уравнения $y''+ay'+by=0$ подстановка $y=e^{rt}$ приводит к характеристическому уравнению $r^2+ar+b=0$. Если корни $r_1\ne r_2$ действительны, общее решение — $C_1e^{r_1t}+C_2e^{r_2t}$. При двойном корне $r$ получаем $(C_1+C_2t)e^{rt}$. Для сопряжённых корней $\alpha\pm i\beta$ вещественное общее решение имеет вид $e^{\alpha t}(C_1\cos\beta t+C_2\sin\beta t)$.

Для неоднородного уравнения общее решение — сумма одного частного решения и общего решения соответствующего однородного уравнения. Начальные значения $y(t_0),y'(t_0)$ определяют коэффициенты единственным образом при непрерывных коэффициентах.

## Системы

Система $y'=A(t)y+g(t)$ включает уравнение второго порядка после введения новых переменных. Если $\Phi$ — фундаментальная матрица однородной системы, то вариация постоянной даёт

$$y(t)=\Phi(t)\left(c+\int_{t_0}^{t}\Phi(s)^{-1}g(s)\,ds\right).$$

Матрица $\Phi$ должна быть обратимой; это обеспечивается линейной независимостью её столбцов в одной точке для системы с непрерывной матрицей $A$.

<summary>1. Решите y″ + y = 0, y(0) = 0, y′(0) = 1.</summary>

Корни характеристического уравнения равны $\pm i$. Общее решение $C_1\cos t+C_2\sin t$; начальные условия дают $y=\sin t$.

<summary>2. Найдите решение y′ + y = 0, y(0) = 2.</summary>

Интегрирующий множитель $e^t$ даёт $(e^ty)'=0$, поэтому $y=2e^{-t}$.

</details>
